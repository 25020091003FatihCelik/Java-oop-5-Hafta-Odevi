# Java OOP Practice - Chapter 11 Exercises

This repository contains my solutions for selected exercises from Chapter 11 
(*Inheritance and Polymorphism*) of Daniel Liang's *Introduction to Java Programming 
and Data Structures*. 

The aim of this project is to strengthen my understanding of class hierarchies, 
code reusability, and dynamic binding in Java.

## Highlights & Key Concepts
- Superclasses and Subclasses (`super` keyword usage)
- Method Overriding vs. Method Overloading
- Polymorphism and Dynamic Binding
- Protected Visibility & Modifier Rules
- The `Object` Class and `toString()` / `equals()` Overriding
- ArrayList of Objects and Casting (`instanceof` operator)
